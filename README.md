Данные

Использован учебный набор данных посещаемости группы за период с 03.09.2026 по 19.11.2026.

* Количество студентов: 28.
* Количество занятий: 12.
* Формат данных: CSV UTF-8.
* Обезличивание: вместо фамилий используются уникальные коды студентов S01–S28. Персональные данные отсутствуют.

Выводы

1. Средняя посещаемость группы за весь период составила 66,9%.
2. Наибольшая посещаемость зафиксирована 08.10.2026 и составила 82,1%.
3. У 16 из 28 студентов посещаемость составила 75% занятий и более.

Проверка

Вручную проверена посещаемость за 03.09.2026.

Формула: количество присутствовавших / количество студентов с заполненными данными × 100%.

Результат: 20 / 26 × 100% = 76,9%.

Результат расчёта необходимо сопоставить с показателем на графике.
